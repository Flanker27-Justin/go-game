# 五子棋 · 使用说明

一个五子棋小游戏，支持**双人对战 / 人机对战（三档 AI + 教育模式）/ 微信联机实时对战**，并预留了国际象棋、围棋、中国象棋的扩展接口。联机侧支持**一键邀请**（建房自动复制链接 + 大字房间号 + 二维码扫码入局）、**棋盘格数可选**（13/15/19，建房时选择，联机中房主随时可改=双方清空重开）、**联机公平猜先**（服务器掷硬币，赢家自选执黑/执白）、**断线自动重连**（刷新/断网 60 秒内自动回房并恢复局面）、**房间保留**（对方离开后可重新邀请原对方或新对手）、**心跳保活**、终局**再来一局**，以及**玩家栏 + 气泡聊天 + 语音/视频通话**（异地也能边下棋边交流）。另有**开局猜先**（抛硬币 / 猜奇偶决定谁执黑），配合 cpolar 公网隧道可异地朋友点链接即玩。

> **想要最省事的启动方式**：双击 `outputs/启动五子棋.bat` 即可——它会自动检查 Node.js、启动服务器、打印本机与局域网访问地址，并打开浏览器。详见第二节。

> （浏览器会直接报 `GomokuAI is not defined`）。

## 二、快速开始（本机单机）

### 方式一：一键启动（推荐）

双击 `outputs/启动五子棋.bat`。脚本会自动完成：

1. 检查 Node.js（**没装会给出下载地址与 `winget` 安装命令**，不会一闪而过）；
2. 选择端口（默认 8123，**若被占用自动顺延**到 8124/8125…）；
3. 启动服务器并把日志写到 `logs/server.log`；
4. 打印两个地址：本机 `http://127.0.0.1:8123/`、局域网 `http://192.168.x.x:8123/`（手机联机用这个）；
5. 自动打开浏览器。

**关闭那个窗口即停止服务器。** 进阶用法：

```powershell
# 指定端口 / 不自动开浏览器
powershell -ExecutionPolicy Bypass -File 启动五子棋.ps1 -Port 9000 -NoBrowser
```

### 方式二：手动启动

1. 安装 [Node.js](https://nodejs.org)（任意 LTS 版本）。
2. 在 `outputs` 目录启动服务器：

   ```bash
   node gomoku-server.js
   ```

3. 浏览器打开 <http://127.0.0.1:8123/> 即可游玩。
   - 不想用服务器、只玩单机模式也可以：**双击 `gomoku.html`**，但必须保证同目录下
     `engine/gomoku-ai.js` 存在（浏览器在 `file://` 下会拒绝跨目录请求，缺失时页面无法工作）。
     单机模式下在线对战功能不可用。

## 三、和手机上的朋友联机（局域网 + 微信）

1. **电脑启动服务器**：`node gomoku-server.js`（默认端口 8123）。
2. **查询电脑的局域网 IP**：Windows 上打开命令提示符执行 `ipconfig`，找到"无线局域网适配器 / 以太网适配器"下的 **IPv4 地址**，形如 `192.168.1.6`。
3. **放行防火墙**（首次需要，否则手机打不开）：
   - 以管理员身份运行 PowerShell，执行：
     ```powershell
     netsh advfirewall firewall add rule name="Gomoku8123" dir=in action=allow protocol=TCP localport=8123
     ```
   - 或：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 → TCP 8123 → 允许连接。
4. **电脑端建房**：浏览器打开 `http://你的IP:8123/` → 点【在线对战】→ 先选好**棋盘大小**（13/15/19，之后房主仍可随时改，改即双方清空重开）→【创建房间】。建房成功后页面会**自动复制邀请链接**、以大字显示**房间号**，并生成**二维码**（手机相机/微信扫一扫即可入局）。
5. **微信发给对方**：邀请链接已自动复制，直接粘贴到微信/QQ 发给对方即可（也可点【复制链接】重新复制；支持把 `gomoku.html` 文件发给对方让对方浏览器打开）。
6. **手机端加入**：对方手机浏览器直接打开这条链接（或扫码），页面会自动进入在线模式并加入房间，无需手动输入房间号；棋盘大小以房主建房时选择的为准。
   - 关键要求：**手机和电脑连同一个 WiFi/路由器**；页面会自动把 WebSocket 地址指向当前 IP，无需手动配置。
   - **公平猜先（默认开启）**：双方就位后自动弹出猜先，服务器掷硬币、赢家自选执黑（先手）或执白；不想要可建房前关掉“开局猜先”开关，恢复“房主黑、加入者白”。**刷新页面 / 断网不算退出**：60 秒内自动重连并恢复当前局面；点【断开】才是主动离开。
7. **对局中的交流**：页面顶部玩家栏实时显示双方执子、轮到谁、最近落子；【💬 聊天】支持气泡消息、快捷表情/常用语、未读角标与自定义昵称；【📞 语音】【📹 视频】可直接与对方实时通话（需要 HTTPS 访问，cpolar 公网 https 或本机 localhost 均可）。对方断线时会收到"对方暂时离开"倒计时，重连后自动继续；对方离开后房间保留，把邀请链接再发一次即可重新加入。

## 四、公网联机（cpolar 内网穿透，适合异地朋友）

用 [cpolar](https://www.cpolar.com/)（免费版即可）把本机 8123 端口映射成公网地址，异地的朋友也能直接玩：

1. 安装并注册 cpolar 客户端，启动后登录。
2. **启动五子棋服务器**：在 `outputs` 目录执行 `node gomoku-server.js`。
3. **创建 HTTP 隧道**：命令行执行 `cpolar http 8123`（或在 cpolar 后台 Web 面板添加一条指向本机 8123 的 http 隧道）。成功后会得到一个公网地址，形如 `https://xxxxxxxx.r1.cpolar.cn`。
4. **电脑端建房**：浏览器打开 cpolar 公网地址 →【在线对战】→ 先选好**棋盘大小**（13/15/19，之后房主仍可随时改，改即双方清空重开）→【创建房间】。建房后邀请链接**自动复制**并带公网域名（形如 `https://xxxxxxxx.r1.cpolar.cn/?room=AB12C`），页面同时显示大字房间号与**二维码**。
5. **微信发给对方**：直接把已复制的链接粘贴给异地的朋友（或点【分享（微信）】调起系统分享）。
6. **对方直接入局**：朋友在手机/电脑浏览器打开链接或扫码即自动加入房间开始对弈（cpolar 的 http 隧道同时转发 WebSocket，无需额外配置）；手机扫码后长按二维码中任意一片区域也能唤起浏览器打开。对局中可用玩家栏看执子/回合，用【💬 聊天】文字交流、用【📞/📹】语音视频通话（https 地址下可用）。
   - **语音/视频怎么实现**：无需任何额外配置——页面已内置 WebRTC 通话，信令走你的 WebSocket 服务器转发，媒体流经公共 STUN 打洞直连。只需满足两点即可用：① 双方都在房间内且对方在线（通话按钮才可点）；② 页面是 **https**（cpolar 免费版就是 https）。点【📞 语音】→ 对方弹来电横幅 → 点【接听】即通话；通话中可【静音】【关摄像头】【挂断】。跨严格 NAT 连不上时，把 TURN 服务器地址加入 `outputs/gomoku.html` 顶部 `ICE_SERVERS` 配置即可。

> 提示：
> - 免费版 cpolar 的随机域名每次重启隧道都会变化，每次开房前请重新【复制链接】发给对方；固定域名需 cpolar 付费套餐。
> - 若你使用 cpolar 的 **TCP 隧道**而非 http 隧道，请在【服务器】输入框手动填写 `ws://xxx.cpolar.cn:端口` 形式的地址。
> - 不想用 cpolar 时，也可以租一台公网云服务器，把 `gomoku.html`、`gomoku-server.js`、`games/` 上传后执行 `node gomoku-server.js`，并放行安全组 TCP 8123。

## 五、玩法与功能

- **三种模式**
  - 双人：同一屏幕轮流落子。
  - 人机：玩家与 AI 对弈（默认玩家执黑、AI 执白）。
  - 在线：通过邀请链接/房间号实时对战（见第三、四节）。
- **开局猜先（双人/人机/联机模式）**
  - 设置区"开局猜先"开关默认开启；每局开始前弹出小游戏决定谁执黑（黑棋先手）。
  - 双人/人机：**抛硬币**（正面=玩家1/你 赢，反面=玩家2/AI 赢）或**猜奇偶**（系统藏 1~5 颗棋子，猜中者赢）。
  - **联机猜先**：服务器权威掷硬币（客户端无法作弊），随机选一方先猜正/反面，猜中者赢；赢家自选执黑（先手）或执白，颜色与角色（房主/加入者）解耦——加入者也可能是黑棋。猜先中途刷新/断线会自动补发状态继续。
  - 赢家可自选**执黑（先手）**或**执白**；人机模式下玩家也可执白（AI 执黑先行），AI 难度与教育点评都会自动按新执子颜色工作。
  - 不想要这步可直接点【跳过】，默认玩家1/你（联机默认房主）执黑。
- **一键邀请（在线模式）**
  - 建房成功后**自动复制邀请链接**、大字显示房间号并生成**二维码**（内嵌编码器，零依赖）；对方打开链接或扫码即自动入局，无需输入房间号。
  - 邀请区（链接 + 复制 + 扫码）在**对局全程保留**：点【扫码入局】可随时展开/收起二维码，方便对方中途掉线后重新扫码进入。
  - 支持局域网 IP 与 cpolar 公网地址自动适配；也支持 `?invite=房间号` 两种参数写法。
- **玩家栏 + 气泡聊天（在线模式）**
  - 棋盘上方玩家栏实时展示双方：执子颜色、回合高亮（轮到谁谁亮起）、最近落子位置（第 N 手），一眼看清局面归属。
  - 【💬 聊天】默认折叠不占棋盘空间：收到新消息时按钮点亮并显示**未读角标**；气泡式消息带发送者昵称与时间戳；输入框上方有一排**快捷表情/常用语**（😄 👍 该你了 好棋！ 再来一局？…），点一下即发送。
  - **昵称**：入局后在"昵称"输入框输入并回车，双方玩家栏与聊天即时同步（≤12 字，随时可改）。
- **语音 / 视频通话（在线模式）**
  - 入局后点【📞 语音】或【📹 视频】发起通话，对方收到来电横幅可接听/拒绝；通话中可**静音、关摄像头、挂断**，30 秒无人接听自动取消。
  - 技术说明：基于浏览器原生 WebRTC + 公共 STUN 服务器做 P2P 直连，信令由本服务器转发，**零第三方依赖**。需要 **HTTPS 安全上下文**（cpolar 公网 https、或本机 `http://localhost`/`127.0.0.1`）；普通局域网 IP 的 http 访问受浏览器限制无法打开麦克风。跨严格 NAT 时若连不上，可自行配置 TURN 服务器。
- **联机中修改配置**
  - **棋盘大小**：**房主随时可改** 13/15/19（含对局中），改大小=双方棋盘清空重开一局（黑先），双方同步；加入者不可改，仅房主有权限。
  - **昵称**：双方随时可改并同步给对方（见上）。
- **对方离开后房间保留**
  - 对方（白棋）主动断开或重连超时，**房间与当前棋局保留**：房主收到提示，邀请区自动重新出现，把链接再发一次即可让原对方或新对手直接加入并恢复棋局。
  - 房主想清空棋局等待新对手，可点【断开】后重新建房；对方在线时【断开】会结束当前对局。
  - 对方刷新/断线 60 秒内算"暂时离开"：本端暂停落子并显示倒计时，对方自动重连后继续对局。
- **断线自动重连（在线模式）**
  - 建房/加入时下发重连凭证；**刷新页面或短暂断网不算退出**，页面自动按 1s→10s 指数退避重连，60 秒窗口内用服务端权威快照恢复棋盘/回合/胜负，双方继续对局。
  - 对方断线期间本地会暂停落子并提示"对方暂时离开，等待重连…（60 秒内自动恢复）"；重连成功提示"对方已重连"。
  - 超时未归才判定对方离开；点【断开】才是主动退出。服务器每 15s 心跳探活、45s 无响应回收僵尸连接，并限制单条消息 ≤8KB、每秒 ≤20 条防刷。
- **再来一局（在线模式）**
  - 对局结束后任一方点击【再来一局】，双方棋盘同步清零、**执子颜色不变**（沿用本局猜先结果或默认颜色），直接开下一盘，无需重新建房。
- **棋盘格数**：13 / 15 / 19 可选（默认 19），切换即新开一局；在线模式建房时选择、**房主随时可改**（改大小即双方清空重开，加入者无权限），双人/人机模式随时可切。
- **AI 三档难度**
  - 简单：单步启发式打分，出棋随机变化最大，适合新手；补上了最基本的"能赢就赢 / 对方要赢必须挡"。
  - 中等：棋型组合评分 + 一步必杀/挡杀检测 + VCF 冲四连杀 + VCT 活三链杀（自动选**手数最短**的杀棋路线）+ 对方双杀/活三链防守。
  - 困难：在中等基础上叠加 Alpha-Beta 剪枝搜索，并采用**迭代加深**（预算内自动从 3 层加深，中盘 5 层 / 残局 6 层），19 路棋盘单步最长约 2.5 秒（分层时间盒控制：每层分配预算，超时立即用已完成层的结果落子，不会长时间无响应），中后盘能看穿更长杀棋、更快兑现优势。
- **置换表 + 历史启发（困难档搜索加速）**
  - **Zobrist 置换表**：每个局面（含"轮到谁"）的搜索结果缓存复用，迭代加深各层与不同分支汇聚时不再重复展开同一局面，同一预算下能搜得更深；每次搜索开始重建哈希并清空缓存，结果完全确定、不受上一步影响。
  - **历史启发**：引发剪枝的"好手"按深度平方累加历史分，候选按历史分优先尝试，让剪枝更早发生；开局阶段历史分全为 0，保持原有启发式顺序，不影响开局套路与随机变化。
- **强制走法搜索（困难档核心提升）**
  - 搜索节点会先判断双方的"强制威胁"：对方可一手成活四/成五时必须先堵；自己能一手冲四/活四时只搜这些强制点。
  - 等于把"连续冲四杀棋"的思路融进博弈树：同一预算下分支数从十几个降到几个，能顺着杀棋链多看 2~3 层，残局对攻、快速兑现优势的能力明显更强。
  - 只把"一手形成双威胁"的冲四当强制手；单一冲四会被对方一手堵死，若强制只搜它会盲目冲四挥霍机会——普通冲四仍保留在候选里按启发式高分优先尝试。
- **双三"阵法杀招"（中盘转化优势的关键）**
  - 新增双威胁检测：一手能同时形成两个"活三以上"威胁（双三 / 活三+冲四 / 双四）时，只要对方没有更快威胁（不能一步成五、不能一手成活四），AI 会主动下出这个必胜阵型，把前中盘积累的优势直接兑现成杀棋。
  - 防守同等级的威胁时，优先选"挡住又能顺手形成双威胁"的落点；安静局面下布子优先做双威胁结构，而不是零散地凑单线。
  - 若对方已有活三等更快威胁，双杀不成立，AI 会先防守——不会为了贪阵法而漏防。
- **VCT 活三链杀（连续活三强制胜）**
  - 在双杀之后新增 VCT 搜索：AI 每一步都落成对方必须防守的活三/双三，模拟对方所有可能的堵法（AND 节点），全部堵不死才认定这条活三链必胜——这是中盘把优势转化为胜势的关键手段。
  - 对方存在活三链时，AI 会优先抢占对方活三/冲四的开放端点，选“堵住又能顺势反击”的点，而不是盲目进攻。
  - 10 层 / 5000 节点 / 300ms 预算双重上限，单步不会卡顿；命中时教学点评会提示“AI 发现了一条连续活三的杀棋路线（VCT）”。
- **先手权（tempo）评估**
  - 静态评估加入"轮到谁走"的修正：双方各有一个活三时，先手方下一手就能把活三变活四锁定胜局，评估不再误判成均势，AI 攻防取舍更准确。
- **防守权衡（不机械堵棋）**
  - AI 会区分“必须挡”和“可以放”的棋型：对方的**活三/活四/冲四**必须立即防守；但对方三连一端已被堵死（眠三）时，即使另一头落子能冲四，也只是一步步被挡、不构成杀棋，AI 会交给全局搜索/评分权衡，优先做能赢的棋，而不是处处设防。
  - 只在对方存在 VCF 连续冲四杀棋时，AI 才会强制堵冲四端点。
- **开局库（前 9 手定式）**
  - 内置由引擎自身搜索生成的**开局库**（覆盖 0~8 子局面、860 个规范化局面、2590 条应答，按 8 对称折叠：旋转/镜像同一开局命中同一表项）。
  - AI 前 9 手直接查库应手，响应极快、开局有章法；同一定式带权随机（困难档收敛、中等适度），配合上面的随机机制保证"同一开局不再永远同一手"。
  - 开局库同样服务于教育模式：推荐点与点评会给出库内定式应手。
- **AI 出棋变幻莫测**
  - 开局与普通选点会在得分最高的前几名里**带权随机**：同一开局不再永远同一手（难度越高变化越小，困难档只在两个同等级好点间浮动），强度几乎不受影响。
- **对手意图判断**
  - AI 会分析你每一步的目的（活四 / 冲四 / 活三 / 双杀陷阱 / 防守 / 布局）。
  - 发现你在酝酿双三/三四/双四时，会**抢先堵住关键点**让陷阱无法成形。
  - 教育模式下 AI 思路会明确说出来，如"AI 识破你的活三意图，先落子压制你的发展"。
- **教育模式（仅人机模式）**
  - 开启后，AI 会点评你每一步（成五 / 错过必杀 / 防守警告 / 双杀赞美 / 更优推荐 / 弱棋批评 / 棋型描述）。
  - AI 自己走出 VCF 冲四连杀 / VCT 活三链杀时，点评会明确说明这条杀棋路线，方便你学习如何把优势兑现成胜势。
  - "推荐点"开关：在棋盘上用绿色圆圈标出 AI 认为的最佳落点。
  - AI 落子后还会附带一句思路说明。
- **胜率预测（仅人机模式，可选开关）**
  - 设置区新增"胜率显示"开关（默认开启），开启后在状态栏下方显示"你 x% / AI y%"的渐变胜率条（绿色=你、红色=AI）。
  - 胜率由当前局面的静态评估分实时估算：空盘接近 50%，一方成活四/一步成五时直接锁定接近 100%。
  - 色条带 50% 白色中线：左侧绿色为你、右侧红色为 AI，谁占优一眼可辨；两侧百分比统一四舍五入到 0.1%。
  - 98% 封顶只对"轮到的一方"的一步成五生效：冲四这类对方下一步可挡的棋型不会误报成锁定胜局。
  - 双三/双威胁等"强而不必胜"的棋型在胜率估算中打折处理，只显示 60~80% 区间，避免三个连子就飙到 98% 的失真。
  - 关闭开关或切到双人/在线模式时自动隐藏；人机模式下开关不可用时为置灰状态。
- **悔棋 / 重新开始**：人机模式悔棋会同时撤回玩家与 AI 的两步；AI 思考中不可悔棋。

## 六、扩展新棋种（预留接口）

`games/` 目录已给出骨架。实现方式：

1. 仿照 `games/_adapter-template.js` 与 `gomoku.html` 末尾的 `gomokuAdapter`，实现同一套适配器接口（`id / name / modes / onEnter / onCanvasClick / onUndo / ...`）。
2. 在 `games/chess.js` 等文件中实现规则逻辑后，调用框架的 `registerGame(id, adapter)` 注册。
3. 在 `gomoku.html` 的游戏下拉框中即可切换。
4. 需要 AI 时，可参考 `engine/gomoku-ai.js` 的组织方式：做成 UMD 模块（浏览器挂全局、Node 可 `require`），
   对外暴露 `setBoardSize / setColors / getBestMove` 等接口，页面侧只负责调用，
   这样 AI 能被 Node 测试直接加载、也便于单独做基准与对弈评估。

## 七、AI 引擎与开发说明

**架构**：AI 引擎是独立模块 `engine/gomoku-ai.js`，是**唯一权威实现**；页面与全部测试都从它加载，
不再有第二份实现。页面里的 `const AI = GomokuAI` 就是它的引用。

**改引擎的流程**：

```bash
# 1) 直接改 outputs/engine/gomoku-ai.js（常量与函数都在这里）
# 2) 规范化并自检（幂等，会校验函数完整性/未定义引用/注释配平/语法）
node work/build-engine.js
# 3) 跑战术题库与断言（秒级，必须全绿）
node work/positions-test.js && node work/ai-threat-test.js && node work/ai-scoring-test.js
# 4) 若要评估棋力，用配对判据（见下）
node work/duel2.js --a work/archive/新引擎.js --b outputs/engine/gomoku-ai.js --positions 12
```

> **评估棋力必须用 `duel2.js`，不要只看 A/B 胜率。**
> 实测结论：当前引擎存在「执黑必胜」现象，谁执黑谁赢，因此 **A/B 胜率永远是 50%**，
> 无法区分强弱。`duel2.js` 让黑方按预先录制的进攻序列落子，两引擎在同一局面下各自
> 执白、比较存活手数——同一引擎的差值恒为 0（哨兵特性），是目前唯一有区分度的判据。

**已知的棋力瓶颈**（多次实测确认，避免重复踩坑）：

- 一整局中约 **83% 的着法由 getBestMove 的固定战术阶梯直接决定、不经过搜索**，
  因此单独修改搜索参数（宽度、半径、VCF/VCT 窗口、时间预算）或评估函数，
  **几乎不影响实际棋力**——实测 8 项此类改动（含加深搜索、必胜距离、滑动窗口评估）
  全部持平，多数局面决策完全相同。
- 真正要提升棋力属于**重构级**工作：需把 VCF/VCT/双杀的全盘扫描改成增量维护、
  把预算让给 minimax（目标 7~9 层稳定深度），并给叶节点评估提速
  （当前叶节点评估要上千次 `lineInfo`，是性能瓶颈的根源）。

## 九、常见问题

- **双击 `启动五子棋.bat` 一闪而过**：说明启动脚本自身报错了。请改为在 `outputs` 目录打开
  命令行手动执行 `powershell -ExecutionPolicy Bypass -File 启动五子棋.ps1`，即可看到完整报错。
- **提示"未检测到 Node.js"**：按脚本给出的提示安装（<https://nodejs.org/> 或
  `winget install OpenJS.NodeJS.LTS`），装完重新双击即可。
- **端口被占用**：一键启动脚本会**自动顺延**到下一个端口（8124/8125…）并在窗口里显示实际地址；
  也可用 `-Port 9000` 指定。
- **只拷了 `gomoku.html`，页面打不开 AI 功能 / 报 `GomokuAI is not defined`**：
  引擎已拆成独立模块，必须把 `engine/` 目录一起拷贝到 `gomoku.html` 同目录下。
- **手机打不开网页**：确认手机与电脑同一 WiFi；确认防火墙已放行 8123（一键启动窗口里会显示局域网地址）；
  用 `ipconfig` 复查 IP。
- **能打开页面但"正在连接服务器…"卡住**：检查服务器进程是否在运行、端口是否被占用。
- **房间号输不进去**：只接受 5 位字母或数字，会自动过滤非法字符并转大写。
- **页面打开报错**：请用浏览器直接访问 <http://127.0.0.1:8123/>，不要用 `file://` 打开（在线模式依赖 http 服务）。
- **cpolar 地址打不开 / 一直"正在连接服务器"**：确认隧道类型是 http（不是 TCP）、服务器进程在运行；免费版域名变化后要让对方用最新链接重新进入。
- **朋友打开邀请链接但没自动加入**：确认链接里的房间号没被微信截断（复制时完整选中）；若房间已结束或已满，重新建房再发一次；已加入过本房间的浏览器刷新时若提示"房间已满"，请点【断开】清除旧会话后再试。
- **刷新页面后对局没丢，但提示"重连超时"**：断线超过 60 秒窗口，房间已被回收，请让对方重新建房并发新链接。
- **点【复制链接】没反应**：部分手机浏览器限制剪贴板权限，请手动长按邀请链接输入框复制；也可以用手机相机/微信扫一扫页面上方的二维码入局。
- **对方断线后我这边不能落子**：属于正常的"重连窗口"暂停，60 秒内对方重连会自动恢复；超时未归会提示对方离开并结束本局。
- **二维码扫不出来**：内嵌二维码编码器已修复（修正了分块纠错数与格式/版本信息区预留），手机相机或微信扫一扫一般可直接识别；个别手机扫码识别弱时，改用自动复制的邀请链接或手动输入 5 位房间号加入。
- **点【📞 语音】没反应 / 提示需要 HTTPS**：浏览器只允许安全上下文调用麦克风/摄像头。cpolar 公网地址（https）或本机 `http://localhost` 均可；局域网 IP 直连的 http 页面请改用 https 或让双方都连同一 WiFi 后用聊天与棋盘对局。
- **通话连不上（一直"正在呼叫"）**：WebRTC 依赖 NAT 打洞（公共 STUN），极端对称 NAT 下可能失败；可用 TURN 服务器中继（把 TURN 地址加入代码 `ICE_SERVERS` 配置）。
