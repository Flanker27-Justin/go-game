## 一键启动（新增）
需求：每次启动都要「装 Node → 开命令行 → cd 目录 → node gomoku-server.js → 查局域网 IP
→ 浏览器输地址」，配置一圈很麻烦。现提供双击即用：

- `outputs/启动五子棋.bat`：**双击运行**。纯 ASCII 内容（中文只出现在它引用的中文文件名上），
  并用通配符定位同目录的 `.ps1`，因此不受控制台代码页影响；优先调用 PowerShell 7，
  否则回退 Windows PowerShell。
- `outputs/启动五子棋.ps1`：实际逻辑，带 UTF-8 BOM（保证 Windows PowerShell 5.1 下中文不乱码）。依次完成：
  1. 检查 Node.js——未安装时给出官网与 `winget install OpenJS.NodeJS.LTS`，并暂停窗口（不会一闪而过）；
  2. 选择端口——默认 8123，**被占用自动顺延**（最多试 10 个）；
  3. 启动 `gomoku-server.js`，日志写入 `logs/server.log` 与 `.err`；
  4. 等待端口监听（最多 15 秒，区分「仍在启动」与「已崩溃」），失败时打印日志尾部与排查建议；
  5. 追加一次真实 HTTP 请求作为双保险（端口在监听 ≠ 页面能响应）；
  6. 打印本机地址与所有局域网地址（供手机联机）；
  7. 自动打开浏览器；关闭窗口即停止服务器。
- 支持参数：`-Port 9000`、`-NoBrowser`。

验证情况：
- `.ps1` 通过 PowerShell 语法解析；加了 BOM 后用 Windows PowerShell 5.1 读取中文正常；
- 服务器本身在全新端口上验证通过（HTTP 200，页面 140.9KB，`/engine/gomoku-ai.js` 200 / 137.6KB，
  `/engine/opening-book.json` 200）——**这也确认了引擎拆分后不会出现 404 白屏**；
- 端到端的「双击 .bat」在本机沙箱中无法完整执行（沙箱禁止跨进程 spawn，报 `spawn EPERM`，
  且用 Start-Process 拉起的子进程超出作业管理器管理范围），已在脚本内对这类失败做了
  日志输出与排查提示，保证失败时用户能看到原因而不是闪退。
